## 1. 现状与问题

### 1.1 当前数据仓库

| 仓库 | KeyPath | 索引 | 记录数（预估） |
|------|---------|------|---------------|
| notes | id | folder, updatedAt, createdAt | 247 |
| folders | id | parentId, order | 5 |
| tags | name | count | 12 |
| conversations | id | updatedAt, model, personaId | 0 |
| messages | id | conversationId, createdAt, role | 0 |
| calendar | date | intensity | 365 |
| settings | key | - | 20 |
| graph | id | type, topic | 0 |
| social | id | personId, date | 0 |
| circles | id | topic | 0 |

### 1.2 核心问题

| 问题 | 严重程度 | 说明 |
|------|----------|------|
| **无版本迁移机制** | 🔴 高 | DB_VERSION=1，onupgradeneeded只创建表，无迁移逻辑。未来改表结构会丢失数据 |
| **无类型定义** | 🟠 中 | 纯JavaScript，无TypeScript接口，字段含义不明确，容易写错 |
| **无同步字段** | 🟠 中 | 缺少version、deviceId、syncState等字段，V2.0.0多端同步需要大改 |
| **无数据质量检查** | 🟠 中 | 没有完整性约束、一致性检查，脏数据可能积累 |
| **无自动备份** | 🟡 低 | 用户只能手动导出，浏览器清缓存就丢失全部数据 |
| **软删除缺失** | 🟡 低 | 删除是硬删除，无法恢复，同步时无法感知删除 |
| **索引不足** | 🟡 低 | notes缺少tag、type、deleted索引，查询性能会随数据量下降 |

## 2. 数据模型设计原则

### 2.1 六大原则

| 原则 | 说明 |
|------|------|
| **向前兼容** | 新版本能读取旧版本数据，旧版本忽略新字段不报错 |
| **可扩展** | 预留扩展字段（metadata），未来加字段不需要改表结构 |
| **可同步** | 所有实体包含同步所需字段（version、updatedAt、deviceId、deleted） |
| **可恢复** | 软删除+自动备份，误操作可恢复 |
| **可校验** | 每个实体有校验规则，写入前验证数据完整性 |
| **高性能** | 合理设计索引，1000+笔记时查询响应≤50ms |

### 2.2 通用字段（所有实体共享）

```typescript
interface BaseEntity {
  id: string;                    // 唯一标识（nanoid）
  createdAt: string;             // 创建时间（ISO 8601 UTC）
  updatedAt: string;             // 最后修改时间（ISO 8601 UTC）
  version: number;               // 版本号，每次更新+1（同步用）
  deviceId: string;              // 最后修改的设备ID（同步用）
  syncState: 'local' | 'synced' | 'conflict'; // 同步状态
  deleted: boolean;              // 软删除标记
  metadata?: Record<string, any>; // 扩展字段（预留）
}
```

| persons | id | relation, lastContactAt | 联系人 |

| posts | id | circleId, authorId, createdAt | 帖子 |
| personas | id | isDefault, model | AI人设 |

**变更说明**：
- 新增 `graph_nodes` / `graph_edges`（原graph表拆分）
- 新增 `persons` / `posts`（原social表拆分）
- 新增 `personas` / `backups` / `migrations`
- notes新增 `tags`（multiEntry索引）、`type`、`deleted`、`pinned` 索引

### 4.2 索引设计原则

| 原则 | 说明 |
|------|------|
| **查询驱动** | 只为实际查询建索引，不盲目建索引 |
| **组合索引** | 高频组合查询建组合索引（如 folderId+updatedAt） |
| **multiEntry** | 数组字段（如tags）使用multiEntry索引 |
| **索引数量控制** | 单表索引≤6个，避免写入性能下降 |
| **覆盖索引** | 高频查询尽量覆盖索引，避免回表 |

## 5. 同步字段预留

### 5.1 同步字段详解

所有实体继承 `BaseEntity`，包含以下同步字段：

| 字段 | 类型 | 说明 | V1.1.0状态 |
|------|------|------|-----------|
| `version` | number | 版本号，每次更新+1 | ✅ 启用，初始为1 |
| `deviceId` | string | 最后修改的设备ID | ✅ 启用，生成唯一设备ID |
| `syncState` | enum | local / synced / conflict | ✅ 启用，默认local |
| `deleted` | boolean | 软删除标记 | ✅ 启用，默认false |
| `updatedAt` | string | 最后修改时间（ISO 8601 UTC） | ✅ 已有，统一为UTC |
| `createdAt` | string | 创建时间（ISO 8601 UTC） | ✅ 已有，统一为UTC |

### 5.2 设备ID生成

```typescript
// 首次启动时生成设备ID，存储在localStorage
function getDeviceId(): string {
  let deviceId = localStorage.getItem('oneos_device_id');
  if (!deviceId) {
    deviceId = `device-${nanoid(12)}`;
    localStorage.setItem('oneos_device_id', deviceId);

  return deviceId;
```

### 5.3 版本号递增规则

```typescript
// 每次更新实体时，version+1，updatedAt刷新，syncState设为local
function updateEntity<T extends BaseEntity>(id: string, patch: Partial<T>): T {
  const current = getById(id);
  const updated = {
    ...current,
    ...patch,
    version: current.version + 1,
    updatedAt: new Date().toISOString(),
    deviceId: getDeviceId(),
    syncState: 'local' as const,
  };
  save(updated);
  return updated;
}
```

## 6. 数据迁移机制

### 6.1 迁移管理器设计

```typescript
class MigrationManager {
  private migrations: Migration[] = [];
  
  // 注册迁移
  register(migration: Migration): void {
    this.migrations.push(migration);
    this.migrations.sort((a, b) => a.version - b.version);
  }
  
  // 执行迁移
  async migrate(): Promise<MigrationResult> {
    const currentVersion = await this.getCurrentVersion();
    const pending = this.migrations.filter(m => m.version > currentVersion);
    
    const results: MigrationRecord[] = [];
    for (const migration of pending) {
      console.log(`[Migration] v${migration.version}: ${migration.name}`);
      
      // 迁移前自动备份
      await this.createBackupBeforeMigration(migration.version);
      
      try {
        await migration.up(this.db);
        await this.recordMigration(migration, 'success');
        results.push({ version: migration.version, status: 'success' });
      } catch (err) {
        console.error(`[Migration] v${migration.version} 失败:`, err);
        await this.recordMigration(migration, 'failed', err);
        results.push({ version: migration.version, status: 'failed', error: err });
        
        // 失败后尝试回滚
        if (migration.down) {
          try {
            await migration.down(this.db);
            console.log(`[Migration] v${migration.version} 已回滚`);
          } catch (rollbackErr) {
            console.error(`[Migration] v${migration.version} 回滚失败:`, rollbackErr);
          }
        }
        break; // 迁移失败，停止后续迁移
      }
    }
    
    return {
      fromVersion: currentVersion,
      toVersion: this.getLatestVersion(),
      executed: results.length,
      succeeded: results.filter(r => r.status === 'success').length,
      failed: results.filter(r => r.status === 'failed').length,
      results,
    };
  }
  
  // 迁移前自动备份
  private async createBackupBeforeMigration(version: number): Promise<void> {
    const backupData = await this.exportAll();
    const backupMeta: BackupMeta = {
      id: `backup-before-migration-v${version}`,
      type: 'migration',
      createdAt: new Date().toISOString(),
      size: JSON.stringify(backupData).length,
      noteCount: backupData.data.notes?.length || 0,
      version: APP_VERSION,
      schemaVersion: version - 1,
      checksum: await sha256(JSON.stringify(backupData)),
    };
    // 存储备份到IndexedDB（保留最近5份迁移备份）
    await this.saveBackup(backupMeta, backupData);
    await this.cleanupOldBackups(5);
  }
}
```

### 6.2 V1→V2 迁移脚本

```typescript
// migrations/002-add-sync-fields.ts
const migration_002: Migration = {
  version: 2,
  name: 'add-sync-fields-and-restructure',
  
  async up(db: IDBDatabase): Promise<void> {
    // 1. 创建新表
    if (!db.objectStoreNames.contains('graph_nodes')) {
      const store = db.createObjectStore('graph_nodes', { keyPath: 'id' });
      store.createIndex('noteId', 'noteId', { unique: false });
      store.createIndex('type', 'type', { unique: false });
    }
    
    if (!db.objectStoreNames.contains('graph_edges')) {
      const store = db.createObjectStore('graph_edges', { keyPath: 'id' });
      store.createIndex('sourceId', 'sourceId', { unique: false });
      store.createIndex('targetId', 'targetId', { unique: false });
      store.createIndex('type', 'type', { unique: false });
    }
    
    // ... 创建其他新表（persons, posts, personas, backups, migrations）
    
    // 2. 迁移notes表：添加同步字段
    const notesStore = db.transaction('notes', 'readwrite').objectStore('notes');
    // 为现有记录添加默认同步字段
    await new Promise<void>((resolve, reject) => {
      const request = notesStore.openCursor();
      request.onsuccess = (event) => {
        const cursor = (event.target as IDBRequest).result;
        if (cursor) {
          const note = cursor.value;
          const updated = {
            ...note,
            version: note.version || 1,
            deviceId: note.deviceId || 'legacy',
            syncState: note.syncState || 'local',
            deleted: note.deleted || false,
            folderId: note.folderId || note.folder || null, // 字段重命名
            type: note.type || 'markdown',
            metadata: note.metadata || {},
          };
          cursor.update(updated);
          cursor.continue();
        } else {
          resolve();
        }
      };
      request.onerror = () => reject(request.error);
    });
    
    // 3. 创建新索引（需要先删除旧索引再创建）
    // notes表新增 tags multiEntry索引
    if (notesStore.indexNames.contains('tags')) {
      notesStore.deleteIndex('tags');
    }
    notesStore.createIndex('tags', 'tags', { unique: false, multiEntry: true });
    notesStore.createIndex('type', 'type', { unique: false });
    notesStore.createIndex('deleted', 'deleted', { unique: false });
    notesStore.createIndex('pinned', 'pinned', { unique: false });
    
    // 4. 迁移graph表 → graph_nodes + graph_edges
    // ...（拆分逻辑）
    
    // 5. 迁移social表 → persons + posts
    // ...（拆分逻辑）
    
    console.log('[Migration] v2 迁移完成');
  },
  
  async down(db: IDBDatabase): Promise<void> {
    // 回滚：删除新表，恢复旧结构
    if (db.objectStoreNames.contains('graph_nodes')) db.deleteObjectStore('graph_nodes');
    if (db.objectStoreNames.contains('graph_edges')) db.deleteObjectStore('graph_edges');
    // ... 删除其他新表
    
    // 恢复notes表旧索引
    const notesStore = db.transaction('notes', 'readwrite').objectStore('notes');
    if (notesStore.indexNames.contains('tags')) notesStore.deleteIndex('tags');
    if (notesStore.indexNames.contains('type')) notesStore.deleteIndex('type');
    if (notesStore.indexNames.contains('deleted')) notesStore.deleteIndex('deleted');
    if (notesStore.indexNames.contains('pinned')) notesStore.deleteIndex('pinned');

  },
```

### 7.3 备份服务

```typescript
class BackupService {
  // 创建备份
  async createBackup(type: BackupType): Promise<BackupMeta> {
    const data = await this.exportAll();
    const checksum = await sha256(JSON.stringify(data));
    
    const meta: BackupMeta = {
      id: `backup-${nanoid(10)}`,
      type,
      createdAt: new Date().toISOString(),
      size: new Blob([JSON.stringify(data)]).size,
      noteCount: data.data.notes.length,
      version: APP_VERSION,
      schemaVersion: DB_VERSION,
      checksum,
    };
    
    // 存储到IndexedDB
    await this.put('backups', meta);
    await this.put(`backup_data_${meta.id}`, data);
    
    // 清理旧备份
    await this.cleanupOldBackups(type);
    
    return meta;
  }
  
  // 恢复备份
  async restoreBackup(backupId: string): Promise<void> {
    // 1. 验证备份完整性
    const meta = await this.get('backups', backupId);
    const data = await this.get(`backup_data_${backupId}`, backupId);
    const actualChecksum = await sha256(JSON.stringify(data));
    if (actualChecksum !== meta.checksum) {
      throw new Error('备份数据校验失败，可能已损坏');
    }
    
    // 2. 恢复前自动备份当前数据
    await this.createBackup('migration');
    
    // 3. 清空并导入
    for (const storeName of Object.keys(STORES)) {
      await this.clear(storeName);
    }
    await this.importAll(data);
    
    // 4. 验证恢复结果
    await this.verifyDataIntegrity();
  }
  
  // 导出为文件（用户下载）
  async exportToFile(): Promise<void> {
    const data = await this.exportAll();
    const blob = new Blob([JSON.stringify(data, null, 2)], { type: 'application/json' });
    const url = URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url;
    a.download = `oneos-backup-${new Date().toISOString().slice(0, 10)}.json`;
    a.click();
    URL.revokeObjectURL(url);
  }
  
  // 从文件导入
  async importFromFile(file: File): Promise<void> {
    const text = await file.text();
    const data = JSON.parse(text);
    
    // 验证格式
    if (!data.meta || !data.data) {
      throw new Error('无效的备份文件格式');
    }
    
    // 验证校验和
    const actualChecksum = await sha256(JSON.stringify(data));
    if (actualChecksum !== data.meta.checksum) {
      throw new Error('备份文件校验失败，可能已损坏');
    }
    
    // Schema版本检查
    if (data.meta.schemaVersion > DB_VERSION) {
      throw new Error(`备份文件Schema版本(v${data.meta.schemaVersion})高于当前版本(v${DB_VERSION})，请先升级应用`);
    }
    
    // 恢复前备份
    await this.createBackup('migration');
    
    // 导入
    await this.importAll(data);
    
    // 如果备份是旧版本，执行迁移
    if (data.meta.schemaVersion < DB_VERSION) {
      await migrationManager.migrate();
    }
  }
}
```

### 8.1 数据校验规则

| 实体 | 校验规则 | 严重程度 |

```typescript
// 写入前校验，不通过则拒绝写入
function validateNote(note: Partial<Note>): ValidationResult {
  const errors: string[] = [];
  const warnings: string[] = [];
  
  // 必填字段
  if (!note.id) errors.push('id不能为空');
  if (!note.title) errors.push('title不能为空');
  if (note.content === undefined) errors.push('content不能为空');
  
  // 格式校验
  if (note.createdAt && !isValidISODate(note.createdAt)) {
    errors.push('createdAt格式不正确');
  }
  if (note.updatedAt && !isValidISODate(note.updatedAt)) {
    errors.push('updatedAt格式不正确');
  }
  
  // 范围校验
  if (note.elevationLevel !== undefined && (note.elevationLevel < 0 || note.elevationLevel > 5)) {
    errors.push('elevationLevel必须在0-5范围内');
  }
  
  // 类型校验
  if (note.type && !['markdown', 'wysiwyg', 'code', 'canvas'].includes(note.type)) {
    warnings.push(`未知的笔记类型: ${note.type}`);
  }
  
  return {
    valid: errors.length === 0,
    errors,
    warnings,
  };
}
```

```typescript
class DataHealthChecker {
  // 全量数据健康检查
  async checkAll(): Promise<HealthReport> {
    const report: HealthReport = {
      checkedAt: new Date().toISOString(),
      totalIssues: 0,
      criticalIssues: 0,
      issues: [],
    };
    
    // 1. 笔记完整性
    const notes = await noteRepository.findAll();
    for (const note of notes) {
      const validation = validateNote(note);
      if (!validation.valid) {
        report.issues.push({
          entity: 'Note',
          entityId: note.id,
          severity: 'critical',
          field: 'multiple',
          message: validation.errors.join('; '),
        });
      }
    }
    
    // 2. 文件夹引用完整性
    const folders = await folderRepository.findAll();
    const folderIds = new Set(folders.map(f => f.id));
    for (const note of notes) {
      if (note.folderId && !folderIds.has(note.folderId)) {
        report.issues.push({
          entity: 'Note',
          entityId: note.id,
          severity: 'warning',
          field: 'folderId',
          message: `引用了不存在的文件夹: ${note.folderId}`,
          autoFix: () => { note.folderId = null; },
        });
      }
    }
    
    // 3. 文件夹循环引用检测
    const cycle = this.detectFolderCycle(folders);
    if (cycle) {
      report.issues.push({
        entity: 'Folder',
        entityId: cycle[0],
        severity: 'critical',
        field: 'parentId',
        message: `检测到循环引用: ${cycle.join(' → ')}`,
      });
    }
    
    // 4. 标签引用完整性
    // ...
    
    // 5. 日期一致性
    for (const note of notes) {
      if (note.updatedAt < note.createdAt) {
        report.issues.push({
          entity: 'Note',
          entityId: note.id,
          severity: 'warning',
          field: 'updatedAt',
          message: 'updatedAt早于createdAt',
          autoFix: () => { note.updatedAt = note.createdAt; },
        });
      }
    }
    
    // 6. 软删除记录清理（可选，超过30天的已删除记录可物理删除）
    // ...
    
    report.totalIssues = report.issues.length;
    report.criticalIssues = report.issues.filter(i => i.severity === 'critical').length;
    
    return report;
  }
  
  // 自动修复可修复的问题
  async autoFix(report: HealthReport): Promise<number> {
    let fixedCount = 0;
    for (const issue of report.issues) {
      if (issue.autoFix) {
        try {
          await issue.autoFix();
          fixedCount++;
        } catch (err) {
          console.error(`自动修复失败: ${issue.message}`, err);
        }
      }
    }
    return fixedCount;
  }
}
```

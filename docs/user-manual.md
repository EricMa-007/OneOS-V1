## 1. 快速开始

### 1.1 什么是 OneOS？

OneOS 是一款面向知识工作者的**个人操作系统**，将笔记、日程、AI对话、知识图谱、社交等功能整合在一个统一的工作空间中。

**核心理念**：
- **知识整合**：所有信息在一个系统中流动
- **AI增强**：AI作为你的智能助手，无处不在
- **可视化**：知识图谱让你的思维可视化
- **社交重塑**：基于知识的社交，而非基于流量

### 1.2 首次使用

1. **打开应用**：在浏览器中访问 OneOS
2. **创建第一篇笔记**：点击左侧「笔记」→「新建笔记」
3. **体验AI对话**：点击左侧「AI助手」，开始与AI交流
4. **查看知识图谱**：点击左侧「知识图谱」，查看你的知识网络

## 2. 核心功能

### 2.1 笔记系统

#### 创建笔记
- 点击「新建笔记」按钮
- 使用快捷键 `Ctrl/Cmd + N`
- 支持 Markdown 语法

#### 编辑模式
OneOS 编辑器支持三种模式：
1. **编辑模式**：纯 Markdown 编辑
2. **分屏模式**：左侧编辑，右侧实时预览
3. **预览模式**：只读预览渲染效果

切换方式：
- 点击编辑器顶部的模式切换按钮
- 快捷键：`Ctrl/Cmd + P`（预览）、`Ctrl/Cmd + J`（分屏）

#### Markdown 语法支持

| 语法 | 效果 | 示例 |
|------|------|------|
| `# 标题` | 一级标题 | `# 我的笔记` |
| `## 标题` | 二级标题 | `## 章节` |
| `**粗体**` | **粗体** | `**重要内容**` |
| `*斜体*` | *斜体* | `*强调*` |
| `` `代码` `` | `代码` | `` `const x = 1` `` |
| `- 列表` | 无序列表 | `- 第一项` |
| `1. 列表` | 有序列表 | `1. 第一步` |
| `> 引用` | 引用块 | `> 这是引用` |
| `[链接](url)` | 链接 | `[官网](https://...)` |
| `![图片](url)` | 图片 | `![截图](image.png)` |
| `---` | 分割线 | `---` |
| `| 表格 |` | 表格 | 见下方示例 |

**表格示例**：
```markdown
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 内容 | 内容 | 内容 |
```

#### 大纲面板
- 点击编辑器右上角的「大纲」按钮
- 自动提取所有标题
- 点击标题快速跳转

#### 自动保存
- 编辑后 2 秒自动保存
- 底部状态栏显示保存状态
- 支持手动保存：`Ctrl/Cmd + S`

### 2.2 AI 助手

#### 开始对话
1. 点击左侧「AI助手」
2. 在底部输入框输入问题
3. 按 `Enter` 发送，`Shift + Enter` 换行

#### AI 人设系统
OneOS 提供 6 种 AI 人设，适用于不同场景：

| 人设 | 适用场景 | 特点 |
|------|----------|------|
| **通用助手** | 日常问答、通用任务 | 平衡、全面 |
| **写作伙伴** | 文章写作、文案创作 | 创意、文笔好 |
| **编程专家** | 代码编写、技术问题 | 专业、精确 |
| **分析师** | 数据分析、趋势解读 | 理性、数据驱动 |
| **导师** | 学习指导、知识讲解 | 耐心、系统化 |
| **哲学家** | 深度思考、观点探讨 | 思辨、有深度 |

切换人设：点击输入框上方的人设选择器

#### 快捷提示
- 空状态下显示快捷提示卡片
- 点击即可快速开始对话
- 支持自定义快捷提示

#### 对话操作
- **复制回复**：hover AI消息，点击复制按钮
- **重新生成**：对AI回复不满意，点击重新生成
- **搜索历史**：使用搜索框查找历史对话

### 2.3 知识图谱

#### 什么是知识图谱？
知识图谱将你的笔记、标签、概念可视化为节点和连接的网络，帮助你：
- 发现知识之间的关联
- 识别核心知识点
- 探索知识社区

#### 基本操作
- **拖拽**：按住节点拖动，调整位置
- **缩放**：鼠标滚轮缩放，或使用右下角缩放按钮
- **平移**：按住空白区域拖动
- **查看详情**：点击节点，右侧显示详情面板

#### 节点详情面板
点击节点后，右侧显示：
- 节点基本信息（标题、连接数）
- 内容预览
- 标签
- 统计信息（字数、阅读时间）
- 连接的节点列表
- 创建/更新时间
- 快速操作（打开编辑、复制内容）

#### 社区发现
知识图谱自动识别知识社区：
- 同一社区的节点颜色相同
- 社区按大小排序
- 帮助你发现知识聚类

### 2.4 日历

#### 视图切换
- **月视图**：查看整月日程
- **周视图**：查看一周详细安排
- **日视图**：查看当天时间线

#### 创建日程
1. 点击日期格子
2. 填写日程标题、时间、描述
3. 设置提醒（可选）
4. 保存

#### 日程管理
- 拖拽调整时间
- 点击查看详情
- 支持编辑和删除

### 2.5 全局搜索

#### 搜索方式
- 点击顶部搜索框
- 快捷键：`Ctrl/Cmd + K`
- 支持搜索笔记、任务、日程、联系人、消息

#### 搜索技巧
- **精确匹配**：输入完整关键词
- **模糊搜索**：输入部分关键词，自动匹配相似内容
- **类型过滤**：使用筛选器限定搜索类型
- **标签过滤**：按标签筛选结果

#### 搜索结果
- 按相关度排序
- 高亮匹配关键词
- 显示匹配字段（标题/内容/标签）
- 显示相关度百分比

## 3. 使用技巧

### 3.1 高效笔记工作流

1. **快速记录**：使用 `Ctrl/Cmd + N` 快速创建笔记
2. **结构化写作**：善用标题层级，建立清晰结构
3. **标签管理**：为笔记添加标签，便于分类和检索
4. **定期回顾**：使用知识图谱发现知识关联
5. **AI辅助**：遇到问题随时调用AI助手

### 3.2 AI 使用最佳实践

1. **明确人设**：根据任务选择合适的AI人设
2. **上下文充分**：提供足够的背景信息
3. **分步提问**：复杂问题拆分为多个步骤
4. **迭代优化**：不满意就重新生成或补充说明
5. **知识沉淀**：有价值的对话保存为笔记

### 3.3 知识图谱使用技巧

1. **标签驱动**：标签是知识关联的基础，善用标签
2. **定期查看**：每周查看知识图谱，发现新关联
3. **节点整理**：拖拽调整节点位置，优化布局
4. **社区分析**：关注大社区，这是你的核心知识领域
5. **桥梁节点**：识别连接不同社区的桥梁节点

### 3.4 移动端使用

- **底部导航**：移动端使用底部导航栏切换功能
- **响应式布局**：界面自动适配屏幕尺寸
- **触摸优化**：按钮和交互区域适配触摸操作

## 5. 常见问题

### 5.1 数据存储

**Q：我的数据存在哪里？**
A：OneOS 使用浏览器本地存储（IndexedDB），数据保存在你的设备上，不会上传到服务器。

**Q：如何备份数据？**
A：在「设置」→「数据管理」中，可以导出数据为 JSON 文件进行备份。

**Q：清除浏览器缓存会丢失数据吗？**
A：会的。清除浏览器数据会删除 OneOS 的本地数据。建议定期备份。

### 5.2 性能问题

**Q：笔记很多时会卡顿吗？**
A：OneOS 使用虚拟滚动和索引优化，支持数千篇笔记流畅运行。如果遇到卡顿，可以清理不常用的笔记。

**Q：知识图谱节点太多怎么办？**
A：知识图谱默认显示前30个节点。你可以通过标签筛选或搜索来聚焦特定领域。

### 5.3 功能使用

**Q：如何删除笔记？**
A：在笔记列表中，hover 笔记卡片，点击删除按钮。或在编辑器中使用「删除」操作。

**Q：AI回复可以编辑吗？**
A：AI回复本身不可编辑，但你可以复制内容到笔记中进行编辑。

**Q：支持多人协作吗？**
A：当前版本是个人版，多人协作功能在规划中。

### 5.4 移动端

**Q：手机端如何访问？**
A：在手机浏览器中输入 OneOS 的访问地址即可。界面会自动适配移动端。

**Q：移动端功能有删减吗？**
A：核心功能完整保留，部分复杂操作（如知识图谱精细调整）在桌面端体验更佳。

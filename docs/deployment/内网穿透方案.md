# OneOS 内网穿透方案对比与部署指南

## 方案对比

| 方案 | 免费额度 | 速度 | 稳定性 | 配置难度 | 推荐度 |
|------|---------|------|--------|---------|--------|
| **Cloudflare Tunnel** | 无限免费 | 快 | 极高 | 中等 | ⭐⭐⭐⭐⭐ |
| **frp（自建）** | 需要云服务器 | 极快 | 高 | 高 | ⭐⭐⭐⭐ |
| **ngrok** | 1个隧道/40连接/分钟 | 中等 | 高 | 简单 | ⭐⭐⭐ |
| **localtunnel** | 免费但不稳定 | 慢 | 低 | 简单 | ⭐⭐ |
| **花生壳** | 免费1Mbps | 慢 | 中等 | 简单 | ⭐⭐ |

## 推荐方案：Cloudflare Tunnel（零成本、高稳定）

### 优势
- ✅ 完全免费，无流量限制
- ✅ 自带HTTPS，无需申请证书
- ✅ 全球CDN加速，访问速度快
- ✅ 不需要公网IP，不需要路由器端口映射
- ✅ 支持自定义域名（需要有Cloudflare托管的域名）
- ✅ 也可以用Cloudflare提供的免费临时域名（*.trycloudflare.com）

### 方案A：使用免费临时域名（最快上手，5分钟）

不需要域名，不需要注册，直接用Cloudflare提供的临时域名。

**Windows安装：**
```powershell
# 下载 cloudflared
Invoke-WebRequest -Uri "https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe" -OutFile "cloudflared.exe"

# 移动到系统目录
Move-Item cloudflared.exe C:\Windows\System32\
```

**启动隧道：**
```powershell
# 快速启动（临时域名，每次重启会变）
cloudflared tunnel --url http://localhost:3001

# 输出示例：
# +--------------------------------------------------------------------------+
# |  Your quick Tunnel has been created! Visit it at:                       |
# |  https://random-words-1234.trycloudflare.com                           |
# +--------------------------------------------------------------------------+
```

**用PM2守护（24小时运行）：**
```powershell
pm2 start cloudflared --name oneos-tunnel -- tunnel --url http://localhost:3001
pm2 save
```

### 方案B：使用自定义域名（推荐，稳定专业）

需要：
1. 一个域名（可以在阿里云/腾讯云/Namecheap购买，约$10/年）
2. 免费Cloudflare账号
3. 将域名DNS托管到Cloudflare

**步骤：**

1. **注册Cloudflare账号并添加域名**
   - 访问 https://dash.cloudflare.com/sign-up
   - 添加你的域名
   - 按照提示修改域名的NS服务器为Cloudflare的NS

2. **登录cloudflared并创建隧道**
```powershell
# 登录（会打开浏览器授权）
cloudflared tunnel login

# 创建隧道
cloudflared tunnel create oneos-server

# 列出隧道
cloudflared tunnel list
```

3. **配置DNS路由**
```powershell
# 将域名指向隧道（自动添加CNAME记录）
cloudflared tunnel route dns oneos-server oneos.yourdomain.com
```

4. **创建配置文件** `~/.cloudflared/config.yml`
```yaml
tunnel: oneos-server
credentials-file: C:\Users\Administrator\.cloudflared\<tunnel-id>.json

ingress:
  - hostname: oneos.yourdomain.com
    service: http://localhost:3001
  - hostname: app.yourdomain.com
    service: http://localhost:5173
  - service: http_status:404
```

5. **运行隧道**
```powershell
cloudflared tunnel run oneos-server

# 或用PM2守护
pm2 start cloudflared --name oneos-tunnel -- tunnel run oneos-server
pm2 save
```

## 备选方案：frp（需要云服务器）

如果你有云服务器（阿里云/腾讯云，约$5/月），frp是性能最好的方案。

### 服务端（云服务器）
```bash
# 下载frp
wget https://github.com/fatedier/frp/releases/download/v0.52.3/frp_0.52.3_linux_amd64.tar.gz
tar -xzf frp_0.52.3_linux_amd64.tar.gz
cd frp_0.52.3_linux_amd64

# 配置 frps.toml
bindPort = 7000
auth.token = "your-secret-token"

# 启动
./frps -c frps.toml
```

### 客户端（你的电脑）
```powershell
# 下载Windows版frp
# 配置 frpc.toml
serverAddr = "your-server-ip"
serverPort = 7000
auth.token = "your-secret-token"

[[proxies]]
name = "oneos-server"
type = "tcp"
localIP = "127.0.0.1"
localPort = 3001
remotePort = 3001

[[proxies]]
name = "oneos-web"
type = "tcp"
localIP = "127.0.0.1"
localPort = 5173
remotePort = 5173

# 启动
frpc.exe -c frpc.toml
```

## 安全建议

1. **修改JWT_SECRET**：生产环境必须使用强随机密钥
2. **启用HTTPS**：Cloudflare Tunnel自带HTTPS
3. **限制CORS**：只允许你的前端域名访问
4. **定期备份**：每日自动备份数据库
5. **监控日志**：用PM2监控异常重启
6. **速率限制**：可考虑添加express-rate-limit防止暴力破解

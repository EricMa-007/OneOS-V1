## 三、10人测试执行计划

### 第一阶段：基础设施准备（1-2天）

#### 1.1 配置内网穿透（30分钟）

**推荐：Cloudflare Tunnel（免费）**

```powershell
# 1. 下载cloudflared
Invoke-WebRequest -Uri "https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe" -OutFile "cloudflared.exe"
Move-Item cloudflared.exe C:\Windows\System32\

# 2. 快速启动（临时域名，每次重启会变）
cloudflared tunnel --url http://localhost:3001

# 3. 用PM2守护（24小时运行）
pm2 start cloudflared --name oneos-tunnel -- tunnel --url http://localhost:3001
pm2 save
```

启动后会得到一个公网地址，例如：`https://random-words-1234.trycloudflare.com`

**如果需要稳定域名**：
- 注册Cloudflare账号（免费）
- 购买一个域名（约$10/年，阿里云/腾讯云/Namecheap）
- 按照 `docs/deployment/内网穿透方案.md` 中的方案B配置

#### 1.2 修改服务器配置（5分钟）

编辑 `server/.env`（从.env.example复制）：
```
JWT_SECRET=改成一个强随机字符串
PUBLIC_BASE_URL=https://你的公网地址
ALLOWED_ORIGINS=https://你的公网地址,http://localhost:5173
```

然后重启服务器：
```powershell
pm2 restart oneos-server
```

#### 1.3 启动数据备份（5分钟）

```powershell
cd C:\DouBaoXO\OneOS-V1\server
pm2 start node --name oneos-backup -- scripts/backup.js -- --schedule
pm2 save
```

现在PM2应该有3个进程：
- oneos-server（API服务器）
- oneos-tunnel（内网穿透）
- oneos-backup（数据备份）

### 第二阶段：APP打包（1-3天）

#### 2.1 安卓APK打包（1天，需要安装Android SDK）

按照 `docs/deployment/安卓APP打包指南.md` 执行：

1. 安装JDK 17：`winget install Microsoft.OpenJDK.17`
2. 安装Android Studio（含Android SDK）
3. 初始化Capacitor：
   ```powershell
   cd C:\DouBaoXO\OneOS-V1
   npm install @capacitor/core @capacitor/cli @capacitor/android
   npx cap init "OneOS" "com.oneos.app" --web-dir=dist
   npm run build
   npx cap add android
   npx cap sync android
   ```
4. 用Android Studio打开：`npx cap open android`
5. Build → Build APK(s)
6. APK位置：`android/app/build/outputs/apk/debug/app-debug.apk`

#### 2.2 iOS APP打包（1-3天，需要Apple开发者账号）

按照 `docs/deployment/iOSAPP打包指南.md` 执行：

1. **注册Apple开发者账号**（$99/年，审核1-3天）
   - https://developer.apple.com/programs/

2. **注册Expo账号**（免费）
   - https://expo.dev/signup

3. **安装EAS CLI并登录**
   ```powershell
   npm install -g eas-cli
   eas login
   ```

4. **初始化EAS配置**
   ```powershell
   cd C:\DouBaoXO\OneOS-V1
   eas build:configure
   ```

5. **配置app.json**（参考iOS指南中的模板）

6. **构建并提交到TestFlight**
   ```powershell
   # 构建生产版本
   eas build --platform ios --profile production
   
   # 提交到TestFlight
   eas submit --platform ios
   ```

7. **等待苹果审核**（1-2天）

8. **在App Store Connect中创建测试组，添加测试用户的Apple ID**

### 第三阶段：测试用户邀请（1天）

#### 3.1 iOS用户（TestFlight）

1. 在App Store Connect → TestFlight → 测试组
2. 创建测试组"OneOS内测组"
3. 添加测试用户的Apple ID邮箱
4. 用户收到邮件邀请
5. 用户在App Store下载"TestFlight" APP
6. 用户在TestFlight中接受邀请并安装OneOS

#### 3.2 安卓用户（APK直接分发）

方式A：发送APK文件
- 将 `app-debug.apk` 发送给用户（微信/邮件/网盘）
- 用户下载后点击安装（需要允许"未知来源应用"）

方式B：上传到网盘生成下载链接
- 上传APK到百度网盘/腾讯微云
- 生成分享链接发给用户

方式C：用Firebase App Distribution（推荐）
- 免费，支持安卓和iOS
- 用户通过链接安装，自动更新通知

## 七、风险与注意事项

1. **数据安全**：测试阶段数据可能会重置，提前告知测试用户
2. **服务器稳定性**：家用电脑作为服务器，可能会有断电/断网风险，建议配置UPS
3. **iOS审核**：TestFlight审核可能会拒绝，需要准备好APP的基本功能和隐私政策
4. **安卓兼容性**：不同品牌手机（华为/小米/OPPO）可能有不同的权限管理，需要逐一测试
5. **性能监控**：10人同时在线对服务器压力不大，但需要关注内存和CPU使用
6. **备份验证**：定期验证备份文件的可恢复性，不要只备份不验证

## 四、已知问题与限制

### 4.1 已知问题
| 编号 | 问题 | 严重程度 | 状态 |
|------|------|----------|------|
| ISSUE-001 | Firefox/Safari不支持Web Speech API | 中 | 已知限制，已降级处理 |
| ISSUE-002 | Ollama需要本地安装，未安装时AI功能降级 | 低 | 已添加连接检测和提示 |
| ISSUE-003 | 大规模图谱（500+节点）性能下降 | 低 | 已限制默认100节点 |
| ISSUE-004 | PWA离线模式下AI功能不可用 | 低 | 预期行为，需网络连接Ollama |

### 4.2 未来优化方向
1. **WebGL图谱渲染**：支持1000+节点流畅渲染
2. **多语言语音识别**：支持英文/日文等多语言
3. **云端同步**：支持数据云端备份和多设备同步
4. **插件系统**：支持第三方插件扩展功能
5. **移动端原生应用**：打包为iOS/Android原生应用

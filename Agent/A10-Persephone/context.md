## 决策记录

### 文档决策001：文档格式选择
**日期**：2026-08-19
**决策**：采用Markdown作为主要文档格式
**理由**：
1. Markdown简单易学，团队成员都能快速上手
2. Markdown与Git集成良好，版本管理方便
3. Markdown可以轻松转换为HTML/PDF等格式
4. Markdown在开发者社区广泛使用，生态成熟

### 文档决策002：Agent文档结构
**日期**：2026-08-29
**决策**：每个Agent维护三个核心文件（identity.md、context.md、workflow.md）
**理由**：
1. 身份档案（identity）：Agent的人格设定、专业背景、能力水平
2. 上下文压缩（context）：会议纪要、工作总结、决策记录、待办事项
3. 工作流与权限边界（workflow）：工作流程、输入输出、权限边界、协作接口
4. 三个文件分离，便于维护和更新

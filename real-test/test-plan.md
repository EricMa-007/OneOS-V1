# OneOS 慢连接社交系统 — 真实测试方案

## 测试目标
对 OneOS 社交系统进行完整的、真实的端到端测试，模拟两个用户的完整交互流程，验证所有功能的可用性和正确性。

## 测试范围
1. **API层测试** — 所有25+个API端点的功能测试
2. **UI层测试** — 前端社交页面的端到端交互测试
3. **双用户交互模拟** — 用户A和用户B的完整交互流程
4. **边界条件测试** — 异常输入、权限校验、状态转换
5. **数据一致性测试** — 数据库状态与API返回的一致性

- 后端：http://192.168.1.192:3001/api

### 第二阶段：双用户交互模拟（端到端流程）

#### 流程1：通过二维码建立好友关系
1. 用户A登录 → 生成二维码
2. 用户B登录 → 扫码用户A的二维码 → 发送好友请求
3. 用户A查看好友请求 → 接受
4. 验证双方好友列表都有对方

#### 流程2：慢连接消息交互
1. 用户A给用户B发送消息
2. 用户B拉取收件箱 → 看到未读消息
3. 用户B打开对话 → 标记已读 → 回复消息
4. 用户A拉取收件箱 → 看到回复
5. 验证对话历史完整性

#### 流程3：极小圈子互动
1. 用户A创建圈子
2. 用户B发现圈子 → 加入
3. 验证圈子成员列表
4. 用户A创建共享文档
5. 验证圈子文档列表

#### 流程4：人类节点发现
1. 用户A设置话题标签
2. 用户B设置相同话题标签
3. 用户B查看人类节点发现 → 应该能看到用户A
4. 验证共同话题计算正确性

## 测试执行策略
1. 先执行API层完整测试（自动化脚本）
2. 发现问题立即修复
3. 修复后重新执行失败用例
4. 然后执行双用户交互模拟
5. 最后执行UI层端到端测试
6. 所有测试通过后生成最终测试报告

## 缺陷管理
- 每个发现的问题记录：编号、严重程度、复现步骤、预期结果、实际结果、修复方案、修复状态
- 严重程度：P0(致命) / P1(严重) / P2(一般) / P3(建议)
